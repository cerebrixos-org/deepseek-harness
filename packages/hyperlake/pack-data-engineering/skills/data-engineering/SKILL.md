# Data Engineering

Inspect the relevant catalog and existing model definitions before proposing a change. Read pack assets by exact pack and asset id. Confirm the asset dialect is compatible with the selected adapter. Keep inspection read-only. Require approval before DDL, data mutation, deployment, or repository writes. Verify every accepted change against explicit SQL, pipeline, or observability assertions.
