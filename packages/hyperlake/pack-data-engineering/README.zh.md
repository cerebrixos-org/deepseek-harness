# `@cerebrixos/superharness-pack-data-engineering`

[English](README.md) | 中文

此原生 DeepSeek/Cordis 组合插件是行业解决方案包下方可复用的数据工程能力层。它通过共享的确定性能力包工具导出示例银层 DDL、受治理构建流程、新鲜度目标模板、SQL 安全评估和操作指南。

能力包声明一个受治理的数据环境槽位。转换项目、定义仓库和工作流编排器都是可选绑定，因此客户既可单独使用 Hyperlake 提供的能力，也可连接受支持的工具。包内不含凭据或具体客户资源 ID。

## 模型体验

### 数据工程指南与资产

#### 模型可见内容

简洁的数据工程提示段、一份能力包目录说明，以及仅在调用 `superharness_pack_asset_read` 后返回的资产原始内容。

#### Token 影响

提示段固定；说明和资产内容通过显式工具结果追加。

#### KV Cache 影响

指南是稳定的提示段。安装或移除组合包时请求前缀改变一次；资产读取结果追加到历史中。

## 已知限制与后续工作

- 示例仅作为起点；执行和审批仍由所选适配器负责。
