# `@cerebrixos/superharness-packs`

[English](README.md) | 中文

此包是 Hyperlake SuperHarness 的可移植能力包注册表。能力包既是可安装的 DeepSeek/Cordis 组合插件，也是包含 `hyperlake-pack.yaml` 的目录。统一清单支持能力、适配器、领域、资产、治理和解决方案类别，无需创建互不兼容的格式。

能力包资产必须显式导出。`superharness_pack_list`、`superharness_pack_describe`、`superharness_pack_validate` 和 `superharness_pack_asset_read` 让模型能够确定性地发现、验证并读取 DDL、SQL、dbt、notebook、语义模型、仪表板、流程、目标、评估和参考资料。验证通过检查依赖、适配器能力、类型化客户资源绑定、提供方可用性和已附加工具名称，将安装与激活分离。资产路径受限于规范能力包根目录，并包含符号链接解析和可配置的读取字节上限。

能力会声明明确、面向用户的成果。成果可以定义非秘密输入、所需资源槽、工具或确定性工作流入口、审批模式和评估门槛。Harness 核心工具始终可用，不能重复附加。部署可以把已安装插件的可选工具附加到所有能力，或附加到某个能力中的一个或多个成果；还可以发现提供方资源、存储其不透明 ID，并附加带不可变来源信息的知识、工作流或评估。选择成果时，系统会把该契约快照写入会话，并且只开放全局工具和映射到该成果的工具。Agent 作用域限制会隐藏属于其他能力或成果的工具，执行守卫则在会话恢复后继续执行同一规则。

类型化生命周期 API 支持创建和删除用户自定义能力、编辑成果、附加或移除资源与资产、发现提供方资源、管理提供方附件，以及安装或移除配置插件。插件变更需要明确确认，会拒绝含凭据的 URL，并要求重启。该功能默认关闭，只在本地 Hyperlake 配置中明确启用。

注册表不存储凭据，也不执行目标操作。适配器插件把能力包要求连接到 Hyperlake 或客户自有工具。能力限制负责 Agent 可见的组合；目标服务仍负责身份验证、授权、策略和审批执行。

## 模型体验

### 能力包目录与资产

#### 模型可见内容

从 `superharness_pack_list` 到 `superharness_pack_asset_read` 的四个稳定工具，用于选择并读取显式导出的能力包资产。已安装内容仅出现在工具结果中。

#### Token 影响

工具定义固定；所选清单和资产内容仅在调用后追加。

#### KV Cache 影响

四个工具 schema 保持前缀稳定。能力包说明和资产内容只在显式工具调用后进入上下文并追加到会话历史。

## 已知限制与后续工作

- 插件安装只修改所选本地配置。私有仓库和 Git 身份验证保留在 npm 配置或用户 SSH agent 中。
- 资产执行委托给适配器工具；注册表不翻译 Spark SQL、notebook 或引擎专用 DDL。
- 工具组合是运行时可见性和分发边界，不能替代 Hyperlake 或客户提供方中的授权。
