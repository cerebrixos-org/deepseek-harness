# `@cerebrixos/superharness-ui-capability-library`

[English](README.md) | 中文

SuperHarness Web 界面的第一方能力库。它是设置中的第一个顶层分区，以成果为中心展示能力，不会把实现引擎提升为产品概念。用户可以创建能力、配置资源绑定、附加已安装的提供方工具，并选择每个提供方是在本地执行还是通过平台自有工具执行。

共享提供方横跨所有能力；能力专用提供方只为一个能力提供工具。界面从实时工具注册表中选择工具；任意 npm 或本地插件仍由管理员通过 CLI 显式安装。当前 Loader 清单提供实时启用状态和健康信息，不涉及 Rails 服务或重复的 Host API。

## 模型体验

### 能力库界面

#### 模型可见内容

不直接可见。此包通过 `ctx.hyperlakePacks.catalog()` 等类型化 Remote 呈现并修改本地部署配置。选择能力后，Host 能力包注册表负责模型可见提示、工具过滤和执行检查。

#### Token 影响

无；此包不组装模型输入。

#### KV Cache 影响

无；此包既不组装也不发送模型输入。

## 已知限制与后续工作

- 界面只能附加运行时已经安装的工具。新的 npm 或本地插件必须先通过 profile CLI 安装，之后才会出现在此处。
- 提供方元数据绝不携带凭据；凭据仍使用提供方自身的安全配置路径。
