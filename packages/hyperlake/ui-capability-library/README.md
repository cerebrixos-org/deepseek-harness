# `@hyperlake/superharness-ui-capability-library`

Read-only first-party Capability Library for the SuperHarness web interface. It presents outcome-level capabilities and their provisioned, enabled, or connectable resources without promoting implementation engines into product concepts. The current Loader inventory supplies live enablement and health; no Rails service or duplicate host API is involved.

## Model Experience

### Capability Library UI

#### What the model sees

Nothing. This package renders local deployment state in browser Settings and contributes no prompt, tool, message, or provider request. Its `settings.plugins.tab` registration is entirely client-side.

#### Token effect

None; the package does not assemble model input.

#### KV Cache effect

None; the package neither assembles nor sends model input.

## Known Limitations and Deferred Work

- Resource rows report provider availability and supported optional bindings; persistent binding configuration and installation actions are deferred.
